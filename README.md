##ระบบป้องกันการโกงออนไลน์ 

##ฟีเจอร์ที่มีในระบบนี้
- หน้าค้นหาประวัติคนโกง (ค้นหาได้โดยไม่ต้องล็อกอิน)
- ระบบสมัครสมาชิก และ เข้าสู่ระบบ (Auth ด้วย JWT)
- ฟอร์มแจ้งเบาะแสคนโกง (ต้องล็อกอินก่อนถึงจะแจ้งได้)
- **Admin Dashboard**: สำหรับเปลี่ยนสิทธิ์ User ทั่วไปให้เป็น Admin


3. ติดตั้งไลบรารีด้วยคำสั่ง:
   ```bash
   npm install
   ```
4. เริ่มเปิดเซิร์ฟเวอร์:
   ```bash
   npm start
   ```
5. เปิดเบราว์เซอร์ไปที่: **http://localhost:3000**

วิธีตั้งค่า Super Admin คนแรก (เพื่อให้จัดการคนอื่นบนหน้าเว็บได้)
1. เปิดหน้าเว็บ `http://localhost:3000/register.html` และสมัครสมาชิก 1 บัญชี
2. ระบบจะสร้างไฟล์ฐานข้อมูล `fraud_prevention.sqlite` ขึ้นมา
3. ใช้โปรแกรม [DB Browser for SQLite](https://sqlitebrowser.org/) เปิดไฟล์นั้นขึ้นมา
4. ไปที่แท็บ **Execute SQL** และพิมพ์คำสั่งนี้เพื่อตั้งบัญชีแรกเป็นแอดมิน:
   ```sql
   UPDATE Users SET role = 'admin' WHERE id = 1;
   ```
5. กดปุ่ม **Write Changes** 
6. กลับมาที่หน้าเว็บ ล็อกอินด้วยบัญชีนั้น คุณจะเห็นเมนูสีเหลืองชื่อ **"จัดการแอดมิน"** ปรากฏขึ้นมา!
